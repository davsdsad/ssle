# SSLE-1 Benchmark — Nano vs Base

- Dataset: **6000 amostras** (.sds2)
- Épocas: **8**
- Hardware: CPU (sem GPU)

## Tabela comparativa

| Métrica | NANO | BASE |
|---|---|---|
| Vocab size | 227 | 227 |
| Embedding dim | 64 | 256 |
| N-gram order | 2 | 3 |
| Tamanho do modelo (MB) | 0.197 | 0.596 |
| Tempo de treino (s) | 22.99 | 23.21 |
| Loss final | 1.9846 | 1.775 |
| Perplexidade ↓ | 7.262 | 5.689 |
| Distinct-1 ↑ | 0.35 | 0.335 |
| Distinct-2 ↑ | 0.579 | 0.591 |
| Taxa de repetição ↓ | 0.0 | 0.0 |
| Coerência semântica ↑ | 0.2977 | 0.2717 |
| Geração (tokens/s) ↑ | 131.6 | 133.7 |

- O QUE TE IMPEDEM DE TREINAR CONSTRUCAO OU AMBOS

**ACADEMIA | TREINO HIPERTROFIA DIETA**

- O METODO INACREDITAVEL PARA AUMENTAR PEITO BICEPS

- O METODO INACREDITAVEL PARA INVESTIR POUPANCA ORCAMENTO
